## Known errors (from ORST FAQ and articles; not live-checked)

| Wrong | Correct | Why |
|---|---|---|
| เว็ปไซต์ | เว็บไซต์ | b → บ |
| อีเมล์ | อีเมล | pronounced final ล takes no ์ |
| อินเตอร์เน็ต | อินเทอร์เน็ต | ORST computer-term spelling |
| อัพโหลด | อัปโหลด | final p → ป |
| เอเปค | เอเปก | final c → ก |
| นิวยอร์ค | นิวยอร์ก | final k → ก |
| ซุปเปอร์ | ซูเปอร์ | no consonant doubling here |
| เกมส์ (common noun) | เกม | proper names keep their form: เอเชียนเกมส์ |
| เช็ค (inspect) | เช็ก | เช็ค = bank cheque only |
| สันทนาการ | นันทนาการ | |
| มุขตลก | มุกตลก | |
| พิเรน | พิเรนทร์ | |
| แสบสันต์ | แสบสัน | |
| นา ๆ | นานา | loan word, not a repetition |
| ก. ไก่ | ก ไก่ | not an abbreviation |
| จับไฉ่ / มัสหมั่น / แพนง | จับฉ่าย / มัสมั่น / พะแนง | dictionary spelling |
| ละมุนภัณฑ์, กระด้างภัณฑ์, แท่งหรรษา "by ORST" | not ORST coinages | ORST publicly rejected them |

For update, the DB gives the coined form ปรับ(ให้เป็นปัจจุบัน), not a transliteration.
