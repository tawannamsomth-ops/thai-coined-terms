# Transliteration (ทับศัพท์) rules

Use only when no coined-word or dictionary entry exists. Each language has its own rule set; never apply the English rules to another language.

## General principles (ORST rule page)

Source: https://www.orst.go.th/iwfm_list.asp?i=0040002104011001/63ERJ5716056

- "การทับศัพท์ให้ถอดอักษรในภาษาเดิมพอควรแก่การแสดงที่มาของรูปศัพท์ และให้เขียนในรูปที่อ่านได้สะดวกในภาษาไทย"
- Established loanwords in the dictionary keep their form: ช็อกโกเลต, ช็อกโกแลต, เชิ้ต, ก๊าซ, แก๊ส, เอกซเรย์, แอลกอฮอล์.
- Long-established proper names may keep their form: วิกตอเรีย, หลุยส์, โคโลญ.
- Specialist fields may add their own rules.

## English (rules of 2532/1989, Cabinet-approved)

Full rules: http://legacy.orst.go.th/wp-content/uploads/2015/03/หลักเกณฑ์การทับศัพท์อังกฤษ2532.pdf (Royal Gazette copy: https://www.ratchakitcha.soc.go.th/DATA/PDF/2532/A/153/439.PDF). Read the PDF for vowels, clusters, and any case not covered below.

| Element | Thai | Example |
|---|---|---|
| final b | บ | mob → ม็อบ |
| final p | ป | mop → ม็อป, shopping → ชอปปิง |
| initial p | พ, with exceptions | superman → ซูเปอร์แมน, bumper → บัมเปอร์ |
| c before a, o, u, r, l | ค | |
| c before e, i, y | ซ | |
| c/k final | ก | APEC → เอเปก, New York → นิวยอร์ก, topic → ทอปปิก |
| t in Internet | ท | อินเทอร์เน็ต |
| letter X | เอกซ์ | but X-ray → เอกซเรย์ (established) |
| pronounced final l | ล, no ์ | e-mail → อีเมล |

- Tone marks are generally omitted; add one only to avoid clashing with an existing Thai word: coke → โค้ก, coma → โคม่า.
- ็ marks a short vowel where needed to distinguish: log → ล็อก.
- Rule 7.1: after a short-a syllable written with ั, double the final consonant to start the next syllable (bumper → บัมเปอร์). Do not double just because English doubles a letter: ซูเปอร์, not ซุปเปอร์.
